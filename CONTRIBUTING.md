# Contributing

This specification is published under CC BY 4.0. Contributions, feedback, and discussion are welcome.

## How to Contribute

**Questions and discussion:** Open an issue describing your question or topic.

**Proposed changes:** Open an issue describing the change and its rationale before submitting a pull request.

**Errors or omissions:** Open an issue with the section reference and a description of the problem.

## Scope

This repository contains the identity schema specification. Contributions should address the schema's certificate structures, field definitions, lifecycle model, or verification procedures.

Out of scope for this repository:

- Governance contract negotiation protocols
- Settlement protocols
- Marketplace discovery mechanisms
- Governance policy evaluation engines
